# Demo manual

Welcome to the Manual Kit demo. This folder is a plain Markdown manual: GitHub renders it as it is, and the demo
application serves the same files at `/en/manual`.

- [Getting started](01-getting-started.md) — the first steps and a figure you can zoom.
- [Administration](02-admin.md) — only administrators see this chapter in the app.
- [API for developers](04-api.md) — 1.13: the `developer` audience (account `dev`); plain text for everyone else.
- The customer portal at `/portal/help` (account `contact`) serves its own manual root with `customer` chapters only.
